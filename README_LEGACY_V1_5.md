# 글클메 사냥 트래커 v1.5 — 메소 누적 평균 예상치 / 인벤토리 끄고 켜도 안정적

글로벌 클래식 메이플용 Windows 화면 인식 프로그램입니다.
게임 파일 수정·메모리 접근·패킷 분석·자동 키 입력 없이 화면에 실제로
표시되는 경험치와 메소 잔액을 추적합니다.

## 실행

바탕화면의 **글클메 사냥 트래커 (최신)** 바로가기를 실행하거나
**글클메 사냥 트래커 v1.5.exe**를 직접 실행하세요.
Python 설치는 필요 없습니다. 친구 배포 ZIP은 만들지 않습니다.

## 사용법

1. 게임을 켜고 **글클메 사냥 트래커 v1.5.exe** 실행.
2. 설정에서 현재 캐릭터 레벨을 맞춥니다.
3. **▶** 또는 **새 세션**을 클릭합니다. 경험치는 즉시 화면에서 자동 추적합니다.
4. **메소 입력이나 위치 지정은 필요 없습니다.** 프로그램이 게임 화면에서
   인벤토리의 `MESOS` 표시를 자동으로 찾아 처음 감지된 금액을
   **세션 기준 잔액**으로 등록합니다.
5. 이후 인벤토리의 메소 잔액이 **화면에 보일 때마다 자동 갱신**합니다.
   수익과 소비는 모두 포함하여 **순메소 증감**으로 계산합니다.
6. 인벤토리를 닫으면 마지막 잔액을 유지합니다. 다시 열면 자동 탐색하여
   변동된 메소를 반영합니다. 창을 옮겨도 화면 전체에서 탐색합니다.
   **기준 메소**는 그 세션에서 처음 인식한 금액으로 고정되어
   **현재 메소**, **누적 순증감**과 함께 표시됩니다.
7. 경험치는 최근 1/5/10/15/30/60분 기준의 시간당 예상치를 보여 줍니다.
   **메소는 선택한 시간대와 무관하게 기준 메소부터 최근 실제 잔액 확인까지
   누적 평균**을 표시합니다. 사냥 기록 및 CSV 내보내기를 지원합니다.

## v1.5 메소 예상치 수정 (중요)

- 이전 버전은 인벤토리가 닫혀 있는 동안 마지막 메소 잔액을 경험치
  측정마다 반복 기록하여, 인벤토리를 다시 열었을 때 누적 증가량을
  짧은 순간에 주운 메소로 잘못 계산했습니다. **수천~수만 메소/분으로
  튀던 원인**을 제거했습니다.
- 기준 메소는 해당 세션의 **첫 인벤토리 잔액 확인값**으로 고정합니다.
  기준 잔액을 확인한 시점부터 마지막으로 확인된 현재 잔액까지
  실제 사냥 시간(일시정지한 시간 제외)을 사용합니다.
- **순증감 = 현재 메소 − 기준 메소**
- **1분 평균 순증감 = 순증감 ÷ 실제 관측 사냥 시간(분)**
- **1시간 예상 = 1분 평균 순증감 × 60**
- 예: 기준 50,000 → 현재 56,000, 기준 인식 후 실제 사냥 15분이면
  1분 평균 **+400**, 1시간 예상 **+24,000**입니다.
- 인벤토리를 닫으면 잔액을 직접 읽을 수 없으므로 **마지막으로 확인된
  평균 예상치가 유지**됩니다. 다시 열었을 때는 그 사이의 실제 사냥
  시간까지 반영해서 메소 예상치를 다시 계산합니다. 따라서
  인벤토리를 켰다는 이유로 1분당 숫자가 순간 폭증하지 않습니다.
- 시작하고 **첫 잔액 확인 이후 실제 관측 구간이 30초 미만**이면
  오차가 큰 시간당 예측 대신 `—`를 표시합니다. 최소 30초가
  지나 메소 잔액을 다시 확인하면 평균을 계산합니다.
- 메소 그래프도 픽업 순간 속도가 아니라 **시간당 평균의 변화 추세**
  로 바꿨습니다. 인벤토리를 닫았을 때의 정확한 메소 획득 시각은
  확인할 수 없으므로 순간 획득 속도를 추측하지 않습니다.
- **플레이 시간(화면 상단)**은 전체 세션의 실제 경과 시간이며,
  **관측 사냥 시간(메소 카드)**은 기준 잔액부터 마지막 잔액 확인까지
  실제 측정에 사용된 시간입니다. 기준 잔액을 뒤늦게 처음 확인한
  경우 그 이전 기간은 계산에서 제외합니다.
- 숫자는 순수익(소비 및 판매 포함)이며 사냥 메소만 따로 추정하지 않습니다.
- 기존 경험치 추적, 레벨업 계산, 사냥 기록은 변경하지 않았습니다.
- **v1.4 실제 오류 화면의 `기준 60,897 → 현재 31` 오인식 수정:**
  메소 숫자를 읽기 전에 `ITEM INVENTORY` 제목과 실제 잔액 칸 오른쪽
  `MESOS` 표시를 모두 확인합니다. 창 위치를 옮겨도 실제 창 제목의
  너비를 기준으로 잔액 칸 위치를 다시 계산하므로 아이템 개수
  (`31` 등)를 메소로 잘못 읽는 문제를 차단했습니다.
- 잔액이 갑자기 75% 이상 크게 감소하거나 비정상적으로 증가하면
  **추가 관측 3회**로 재확인한 뒤 반영합니다. 이는 아이템 구매 등
  실제 큰 거래도 반영하지만 몇 초 지연될 수 있다는 뜻입니다.
  재확인 중에는 마지막 정상 잔액을 유지합니다.
- 경험치는 기존처럼 **선택한 최근 1/5/10/15/30/60분 동안 실제
  획득한 양**을 기준으로 계산합니다. 마지막 1분 동안 몬스터를
  잡지 않았다면 누적 경험치가 있어도 분당 값은 0이 맞습니다.

## v1.2 속도 개선

- **경험치 전용 OCR 0.5초 간격**: 4K 전체화면을 매번 읽지 않고
  게임 하단 EXP 숫자 부분만 캡처합니다.
- **UI 갱신 확인 주기 약 0.16초**: 읽은 경험치는 다음 UI 갱신 시점에
  표시합니다. 실제 체감 지연은 PC 성능과 화면 OCR 상태에 좌우됩니다.
- **메소 자동 감지와 경험치 추적 분리**: 인벤토리 전체를 찾는 OCR이
  오래 걸려도 경험치 추적을 기다리게 하지 않습니다. 메소는 약 3.5초 간격.
- EXP 숫자와 퍼센트가 확실하게 일치하면 OCR을 1번만 실행하는 빠른
  경로를 사용합니다. 인식이 애매하면 기존 보정과 추가 OCR 검증을 사용합니다.
- 짧은 간격의 측정값으로 프로그램이 무거워지지 않도록 추세 그래프의
  저장 샘플 수를 제한했습니다. 총 획득 경험치·메소는 계속 누적됩니다.
- 저장된 레벨과 실제 레벨이 다르면 시작 시 전후 레벨의 경험치 비율을
  검사해 **두 번 연속 일치할 때 자동 보정**합니다. 실패할 때는 설정에서
  수동으로 맞출 수 있습니다.

## v1.3 작동 불량 수정 (중요)

- v1.2까지는 Windows 바탕화면의 해당 위치를 캡처했기 때문에 다른
  프로그램이 메이플 위에 떠 있으면 메이플 경험치 대신 **다른 창의
  픽셀을 읽어서 경험치가 0으로 남는 문제**가 있었습니다.
- v1.3은 **Windows Graphics Capture로 MapleStory 창 자체를 직접
  캡처**합니다. 다른 게임·브라우저·트래커가 앞에 떠 있어도 실제
  메이플 창의 경험치와 인벤토리 화면을 읽습니다.
- EXP의 퍼센트 기호가 `*`나 `/+ `처럼 오인식되는 글꼴 오류도
  수정했습니다. EXP와 필요 경험치의 비율 검증은 그대로 유지합니다.
- 상단 상태에 **마지막 정상 경험치 인식 시각**과 인식 횟수를 표시합니다.
  `● 일시정지 · ▶ 눌러 재개`가 표시된다면 보라색 ▶를 클릭해야 합니다.
- EXP는 여전히 약 0.5초마다 확인하고 메소는 약 3.5초마다 확인합니다.
  경험치가 **실제로 증가할 때만 누적 획득 EXP가 증가**합니다.
- 구형 Windows나 그래픽 드라이버에서 Windows Graphics Capture
  지원이 없거나 게임을 최소화한 경우에는 추적이 중단될 수 있습니다.

## v1.4 추가 수정

- 실제 글클메 OCR이 EXP를 `7,514 [1 1 *80%]` 또는 `27,514[11 80/+1`
  식으로 잘못 읽어 추적이 장시간 끊기는 문제를 보정했습니다.
  화면의 EXP와 레벨별 필요 경험치 비율을 대조해 숫자를 검증합니다.
- **기준 메소 / 현재 메소 / 누적 순증감**을 동시에 볼 수 있습니다.
- 실제 글클메는 메소 잔액 `60,464`와 `MESOS`를 OCR에서 서로
  다른 줄로 인식합니다. 따라서 `MESOS` 문구를 한 줄로 읽어야만
  잔액을 받아들이는 기존 로직을 개선했습니다. `ITEM INVENTORY`
  제목 위치로부터 인벤토리 바닥의 **숫자만 자동 인식**합니다.
  창 위치가 달라져도 탐색합니다.
- 데이터베이스와 기존 사냥 기록은 지우지 않습니다. 기존 실행 중인
  버전은 닫은 다음 v1.4를 실행하세요.

## 화면 인식의 한계

- 인벤토리가 닫혀 있을 때는 게임 화면에 총 메소 잔액이 표시되지 않으므로
  그 순간의 잔액을 알 수 **없습니다**. 사용자 입력은 불필요하지만
  사냥 중 **인벤토리를 가끔 열어 잔액을 화면에 보이게 해야** 자동 갱신됩니다.
  처음 인벤토리를 열기 전에는 메소 기준 잔액을 정할 수 없습니다.
- 거래·물약 구매·아이템 판매도 순메소 변화에 포함됩니다.
- 메소 표기가 다른 UI 스킨이나 언어 설정에서는 OCR이 실패할 수 있습니다.
  영어 `MESOS` 또는 한국어 `메소` 표기를 기준으로 탐색합니다.
- 다른 창에 가려져도 추적되지만, **메이플 게임을 최소화하거나 종료하면**
  게임 창 자체가 갱신되지 않을 수 있습니다.
- 레벨업 후 경험치 숫자 인식이 지연되면 설정에서 레벨을 다시 맞춰 주세요.
  50레벨 이상 필요 경험치는 고전 메이플 참고값입니다.

## 데이터와 권장 환경

- 각 PC의 `%LOCALAPPDATA%\MapleHuntTracker\`에 기록/설정이 저장됩니다.
  기존 기록은 유지됩니다. **이전 버전과 1.5를 동시에 실행하지 마세요.**
- Windows 10/11과 Windows OCR 한국어 또는 영어 언어팩을 사용합니다.
- 게임의 메모리·네트워크·입력에는 접근하지 않으며 외부 서버로 데이터를
  전송하지 않습니다.
