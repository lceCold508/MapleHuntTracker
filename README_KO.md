# 글클메 사냥 트래커 v1.9.5

글로벌 메이플스토리 클래식 월드에서 경험치와 헤이스트 상태를 확인하는 **Windows 전용, 화면 인식 기반 오버레이**입니다. 게임 메모리·네트워크 패킷·게임 파일에 접근하거나 자동 키 입력을 하지 않습니다.

## 현재 기능

- **1분당 경험치**를 가장 크게 표시하고, **1시간 예상 경험치**, 누적 경험치, 현재 레벨의 필요 경험치, 남은 경험치 및 레벨업 예상 시간을 표시합니다.
- v1.9.5: 경험치를 순간적으로 `0` 또는 이전보다 낮게 오인식하더라도 **잘못된 값을 누적 경험치와 타이머에 반영하지 않습니다.** 실제 사망으로 경험치가 감소했다면 `새 세션`으로 시작점을 재설정해 주세요. 새 세션 시작 직후 OCR이 `0`을 읽으면 첫 유효한 양수 경험치가 나타날 때까지 기준점을 기다립니다.
- **새 세션**으로 측정을 초기화합니다. 이전 세션 기록은 로컬 데이터베이스에 보존합니다.
- 새 세션에서 경험치를 처음 정상적으로 인식한 순간부터 **6분, 10분, 30분, 1시간 누적 경험치**를 동시에 측정합니다. 시간이 지나면 해당 구간의 결과를 확정해 로컬 기록으로 남깁니다. OCR이 길게 끊긴 측정은 임의로 보정하지 않고 기록 불가로 표시합니다.
- 반투명 배경, 항상 위 고정, 창 드래그 이동, 경험치 OCR 자동 재스캔 및 수동 재스캔을 지원합니다.
- 게임 우측 상단의 **헤이스트 아이콘**이 보였다가 사라진 것이 확인되면 짧은 2음 `삐빅` 알림을 울립니다. 아이콘 위에 노란 남은 시간 숫자가 표시되어도 해당 아이콘을 계속 감지하도록 보정합니다. 일시적인 캡처 중단은 종료로 판단하지 않습니다.
- 헤이스트 소리는 설정에서 켜고 끌 수 있으며, 우클릭 메뉴에서 테스트할 수 있습니다.
- **메소 추적은 v1.6 이후 제거**했습니다. 이전의 메소 추적 버전은 `app.py` 및 [v1.5 기록](README_LEGACY_V1_5.md)에 남겨 두었습니다.

## 실행

배포된 `글클메 사냥 트래커 v1.9.5.exe`를 실행합니다. 처음 실행한 경우 헤이스트 버프 아이콘을 한 번 정상 인식해야 종료 알림이 활성화됩니다.

주요 조작:

- 상단 `고정`: 항상 위 전환 / `재검`: EXP OCR 재스캔 / `설정`: 투명도, 레벨, 헤이스트 알림
- `새 세션`: 현재 경험치 측정 기록을 저장한 후 새로 시작
- 우클릭: **헤이스트 알림음 테스트**, EXP 위치 재지정, 사냥 기록

세션 기록과 설정 파일은 `%LOCALAPPDATA%\MapleHuntTracker\`에 저장됩니다. **게임과 트래커가 계속 켜져 있어야 화면 감지 기능이 동작합니다.** 게임을 최소화하면 캡처가 중단될 수 있습니다.

## 소스 실행 / EXE 빌드

Windows PowerShell에서:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe overlay_app.py
```

빌드와 검증:

```powershell
.\build_v1_9_5.ps1
```

빌드 결과는 `dist\MapleHuntTracker_v1_9_5.exe`에 생성됩니다. `app.py`와 `build.ps1`은 이전 v1.5용입니다.

### 개발 파일

| 파일 | 용도 |
|---|---|
| `overlay_app.py` | v1.9.5 사용자 인터페이스, OCR 관리 및 이벤트 처리 |
| `screen.py` · `window_capture.py` | 게임 화면 캡처와 경험치 OCR |
| `engine.py` · `timed_exp.py` | 경험치 누적, 세션, 시간별 측정 및 로컬 기록 |
| `haste_buff.py` · `assets/haste_buff_template.png` | 헤이스트 아이콘 인식 및 2음 알림 |
| `qa_haste_buff.py` · `assets/qa_fixtures/` | 노란 카운트다운 숫자, 오탐, 종료 재검증 |
| `qa_exp_integrity.py` | 0 EXP 오인식 및 음수 경험치 회귀 테스트 |
| `qa_overlay_periods.py` | 경험치 타이머와 오버레이 테스트 |

헤이스트 버프 판정은 이미지 인식이므로 그래픽 UI 확대·축소나 게임 업데이트에 따라 다시 검증해야 할 수 있습니다. 버프 해제 직후 알림이 울리는 시간은 실제 화면 캡처·CPU 부하에 따라 다릅니다.
